# Human Resource Dashboard  

This repository contains a dynamic and visually compelling **Human Resource Dashboard** designed for data-driven insights into employee statistics, attrition trends, job satisfaction ratings, and other HR metrics.  

---

## 📊 **Overview**  

The dashboard provides a snapshot of HR metrics to help HR teams make informed decisions. It includes:  

- **Employee Statistics**: Total employee count, active employees, attrition count, and rate.  
- **Department-wise Attrition**: Pie chart summarizing attrition across HR, Sales, and R&D departments.  
- **Age Group Distribution**: Bar chart illustrating the number of employees by age groups.  
- **Job Satisfaction Ratings**: Heatmap displaying satisfaction levels across various job roles.  
- **Education-wise Attrition**: Bar chart summarizing attrition based on educational qualifications.  
- **Attrition Rate by Gender and Age Group**: Pie charts showing gender-based attrition for different age categories.  

---

## 🚀 **Key Features**  

1. **Interactive Design**: Dynamic filters (Education Level) to explore the data in-depth.  
2. **Comprehensive Visualizations**: Visual representations of attrition trends, employee distribution, and satisfaction scores for quick analysis.  
3. **User-friendly Interface**: Clear labels and easy navigation for HR professionals and stakeholders.

### Key Trends:
